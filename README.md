# Exploratory Data Analysis (EDA)

This project performs Exploratory Data Analysis on a public dataset using Python, Pandas, Matplotlib, and Seaborn.

## Objectives
- Load and explore a public dataset
- Perform data cleaning (missing values, types)
- Generate summary statistics
- Create visualizations
- Document key findings

## Setup
`ash
pip install -r requirements.txt
`

## Usage
Run the Jupyter notebook or Python script to perform analysis.

## Dataset
Using the Titanic dataset from Seaborn (public dataset).
